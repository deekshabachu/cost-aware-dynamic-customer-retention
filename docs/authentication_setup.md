# Customer authentication setup

The API uses the existing `users` table. Registration creates a `customer`
record and returns only its ID and email. It does not sign the customer in.
Login returns a one-hour signed bearer token; the frontend keeps it in
`sessionStorage` for the current browser tab and validates it with `/auth/me`
when the app reloads.

## Configure and run locally (PowerShell)

The repository root `.env.example` documents the variables but is not loaded
automatically. Set them in the same terminal used to launch the API:

```powershell
$env:AUTH_SECRET_KEY = python -c "import secrets; print(secrets.token_urlsafe(48))"
$env:DATABASE_URL = "sqlite:///./data/customer_retention.db"
$env:FRONTEND_ORIGINS = "http://localhost:5173"
python -m uvicorn api.main:app --reload
```

Keep a stable, private `AUTH_SECRET_KEY` across API restarts; changing it
invalidates already issued tokens. The key must contain at least 32 bytes.
For a persistent local setup, generate it once and save it in the operating
system's private environment configuration. Do not commit a real secret.

In a second terminal:

```powershell
cd frontend
npm run dev
```

Vite proxies `/api` to the local API at port 8000. CORS accepts the configured
frontend origin only; its default is `http://localhost:5173`.

## Password and token details

Passwords use Python's scrypt implementation with a random 16-byte salt. This
matches the format already generated by `scripts/seed_demo_data.py`, so the
existing demo accounts remain compatible. Tokens are signed with HMAC-SHA256,
expire after one hour, and are checked against the database user on each
protected request.

The frontend uses tab-scoped `sessionStorage`; it is not an HttpOnly cookie and
JavaScript running in the page can access it. Logout removes the browser's
token, while the stateless token remains valid on the server until its expiry.
This prototype does not yet include rate limiting, password reset, or server-
side token revocation. Use HTTPS and add those controls before public
deployment.
